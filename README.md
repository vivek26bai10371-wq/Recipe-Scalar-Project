# Smart Recipe Ingredient Scaler & Grocery Budgeter

A simple Python console program that scales a recipe for any number of servings and prepares a grocery shopping list with an estimated budget.

## Features
- View the list of available ingredients
- Add a recipe with ingredients, quantities and units
- Scale a recipe to the number of servings you need
- See the estimated cost of the scaled recipe
- Combine all scaled recipes into one grocery list with total budget

## How to Run
1. Install Python from python.org
2. Download or clone this repository
3. Open the folder in VS Code
4. Run `main.py`

## How to Use
1. Choose option 2 to add a recipe
2. Choose option 3 to scale it to new servings
3. Choose option 4 to see the grocery list and total cost
4. Choose option 5 to exit

## Technologies Used
- Python 3 (lists, dictionaries, tuples, functions, loops)
